# demo firewall guide

A collaborative reference guide for recognizing social engineering, phishing indicators, and building security awareness.

## 🎣 Phishing Red Flags
- [ ] **Urgency & Pressure:** Demands immediate action or threatens account closure.
- [ ] **Mismatched Sender Details:** The display name looks legitimate, but the actual email domain has subtle typos (e.g., `supp0rt@micros0ft.com`).
- [ ] **Generic Greetings:** Uses "Dear Customer" instead of your actual name.
- [ ] **Suspicious Links & Attachments:** Hovering over links reveals mismatched URLs or unexpected file attachments (`.exe`, `.scr`, macro-enabled office docs).

## 🏢 Social Engineering Tactics to Watch
- [ ] **Pretexting:** Inventing a scenario or authority role to trick you into sharing data.
- [ ] **Tailgating:** Following an authorized person through a secure door without badging.
- [ ] **Quid Pro Quo:** Offering a fake service or gift in exchange for login credentials.
